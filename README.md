# Super Pro

[superpro.dev](https://superpro.dev) is the concept website of Super Pro, a fictional, humorous software company.

Super Pro is a parody. Its products, prices, reviews, people and quotes are invented, and none of them can be bought,
signed up for or used. It is made by an 18-year-old founder based in Europe who is building a real software company.
